# Wetter App

Kleine Übung in React (useState, useEffect, Vite, Fetch gegen die OpenWeatherMap-API) — Teil meines Lernwegs ganz ohne KI (siehe [Codecademy-Profil](https://www.codecademy.com/profiles/Meisam.dev)).

## Dateien

- `App.jsx`, `main.jsx`, `index.html` — das eigentliche Projekt. Komplett selbst geschrieben, ganz ohne KI.
- `dist/` — der fertig gebaute Vite-Build, der in der Live-Ansicht läuft (mechanisch per `npm run build` erzeugt, kein KI-generierter Code).
- `view.html` — **nicht Teil der Übung.** Nur ein Anzeige-Wrapper (Datei-Tabs + Live-Vorschau) für die Darstellung im Portfolio, mit KI-Unterstützung gebaut.

Der OpenWeatherMap-API-Key im Code ist ein kostenloser, ratenlimitierter Key (bewusst so gelassen wie geschrieben).

---

*Note (EN): `App.jsx`, `main.jsx` and `index.html` are the actual hand-written exercise — no AI involved. `dist/` is the mechanically built output (via `npm run build`). `view.html` is just an AI-assisted viewer wrapper for presenting it on the portfolio site, not part of the exercise itself. The OpenWeatherMap API key in the code is a free, rate-limited key, left as originally written.*
